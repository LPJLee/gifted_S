# 學習樂園 (Gifted Learning Suite)

專為 iPad 與 Apple Pencil 設計的國小自主學習 Web 應用程式集，包含**國語生字聽寫**與**數學直式加減運算**兩大模組。

## 🌟 App 核心功能說明

### 1. 國語生字聽寫 App (`/dictation`)
- **自訂題庫管理**：自由新增字詞、貼上文章快速斷詞解析、匯入匯出題庫 JSON。
- **標準國語發音**：以清晰臺灣國語朗讀生字詞語（支援多段語速）。
- **田字格/米字格手寫**：自動根據詞語字數生成田字格，Apple Pencil 極速連筆手寫、防手掌誤觸。
- **自動計時與防寫鎖定**：倒數計時結束自動防寫鎖定。
- **對答案與批改結算**：學生手寫筆跡與標準楷體國字對照，支援即時評分。

### 2. 國語聽寫模擬測驗 App (`/dictation_exam`)（全新功能）
- **全卷跳題作答**：過程中支援上一題、下一題或題號列自由切換與跳題，即時保存每個字的 Apple Pencil 筆劃。
- **交卷前總覽與個別修改**：完成全卷後可選「交卷」，進入總覽清單檢查所有已寫字跡，可針對任一題目點擊「✏️ 修改」單獨重寫。
- **確定交卷後逐題批改評分**：確定交卷後列出所有寫的內容與標準楷體國字並列對照，由家長或學生手動打勾/打叉評分，並即時統計分數。
- **純文字錯題記錄與錯題本**：評分完後，自動將有「打叉」的題目生字記錄在錯題本中（輕量純文字儲存，不佔用本機圖片空間）。
- **錯題專項重測**：可一鍵針對本次打叉題目或歷次高頻錯字立即發起專項測驗。

### 3. 數學加減模擬測驗 App (`/math_exam`)（全新功能）
- **專項進退位題庫與自訂出題**：
  - 🌟 **基礎加減綜合測驗**：個位進位加法與十幾退位減法（十位數為 1 且退位）精選題型隨機混合出題。
  - 🔟 **十幾減個位數 (必退位減法 45 題全收錄)**：10~18 減 1~9，且個位不夠減需借位的全部 45 道經典題目一網打盡。
  - ➕ **個位數加個位數 (進位加法專項 45 題)**：和在 10~18 的進位加法題目。
  - ⚡ **20以內精熟大題庫 (126 題全合集)**：涵蓋個位加法與十幾退位減法全部組合。
  - 支援「自訂題庫」與自訂算式匯入/匯出。
- **題數與計時彈性設定**：
  - 可自選 5 題、10 題、20 題、50 題、全部出題 (all) 或自訂 1~150 題。
  - 支援不限時 (正向計時)、全卷總時長 (3分、5分、10分) 或單題獨立倒數。
- **作答流程與 Apple Pencil 草稿板**：
  - 支援全卷自由跳題（題號膠囊列、上一題、下一題），切換時獨立保存答案與草稿筆劃。
  - 大尺寸觸控虛擬鍵盤與實體鍵盤（數字鍵、Enter、Backspace）即時輸入。
  - 配備 iPad Apple Pencil 240Hz 直式計算草稿紙（支援直式輔助線、方格紙、一鍵蓋印直式題目、復原與清空）。
- **交卷前總覽與個別修改**：
  - 交卷前展示完整總覽核對清單，未答題目黃色醒目警示，點擊任意卡片可直接返回該題修改。
- **自動批改、詳解核對與錯題專項重測**：
  - 自動 100% 精確批改，統計得分、用時與平均每題秒數。
  - 逐題詳解對照（顯示學生答案 vs 正確答案），可一鍵調閱該題手寫草稿快照。
  - **錯題專項重測**：答錯題目一鍵發起重測，直接鎖定弱點進行強化訓練！
  - 歷史紀錄保存與單筆刪除機制。

### 4. 數學直式加減運算 App (`/math`)
- **雙測驗模式切換**：
  - ⏱️ **總時長模擬測驗模式（全新功能）**：
    - 自訂全卷總時長（如 10 題限時 3 分鐘、5 分鐘或自訂分鐘數/秒數，亦可不限時）。
    - 過程中可自由切換**上一題/下一題**或點擊題號跳題，獨立保留每道題目的答案與 Apple Pencil 手寫計算草稿。
    - 輸入答案按確定直接跳至下一題，**不即時判定對錯**。
    - 交卷前進入**「作答總覽核對清單」**，清楚列出所有題目與已填答案，未填寫題目以警示標籤提示，點擊即可隨時返回修改。
    - 點擊**「確定交卷」**按鈕後，一次統一評估對錯、計算成績與平均作答速度。
  - ⚡ **單題速算挑戰模式**：
    - 每題獨立倒數計時（如 10s、15s、20s），答完即時判定對錯與動畫反饋，節奏緊湊訓練心算與直式敏捷度。
- **自由設定測驗題數**：預設 5、10、20、50 題，亦可自訂任意題數 (1~100 題)。
- **位數與運算型態設定 (最高三位數)**：
  - 一位數 (1~9)、二位數 (10~99)、三位數 (100~999)。
  - 混合位數：二位數 ± 一位數、三位數 ± 二位數、全隨機 (1~3位)。
  - 運算型態：加法 (+)、減法 (-)、加減混合 (±)。減法自動保證不出現負數。
  - 進退位專項練習：隨機、不進退位 (基礎入門)、必須進退位 (直式精熟)。
- **iPad 直式手寫草稿板 (Scratchpad)**：
  - Apple Pencil 低延遲採樣，支援防手掌誤觸 (Palm Rejection 開關)。
  - 直式對齊輔助線模式（百位、十位、個位虛線對位，防止計算對錯位）、方格紙、純白草稿紙切換。
  - 「蓋印直式」功能：一鍵將當前題目以標準直式格式蓋印在草稿紙上。
  - 復原 (Undo)、一鍵清空 (Clear)、橡皮擦、多種筆觸顏色與粗細。
- **成績結算與手寫錯題筆跡回顧**：
  - 統計答對率、總時間與平均每題秒數。
  - 自動保存每題作答時在草稿板上的手寫筆跡快照，點擊「手寫草稿 📝」即可調閱查看計算過程。
  - 完整記錄於本地歷史紀錄庫，可調閱歷次測驗分數、題型與答題速度趨勢。

## 🚀 本地預覽與打包

### 1. 本地啟動伺服器
```bash
npx serve .
# 或使用 Python
python -m http.server 8080
```
開啟瀏覽器前往 `http://localhost:8080/` 即可進入學習大廳。

### 2. 重新打包單檔
若修改了 CSS 或 JS 原始檔，可執行打包腳本生成單檔 HTML：
```bash
# 打包聽寫練習 App
python dictation/build_bundle.py

# 打包聽寫模擬測驗 App
python dictation_exam/build_bundle.py

# 打包數學加減模擬測驗 App
python math_exam/build_bundle.py

# 打包數學直式 App
python math/build_bundle.py
```

### 3. 一鍵部署至 GitHub Pages
```bash
python deploy_github.py
```
部署完成後，即可直接在 iPad Safari 開啟託管網址，並點擊「分享 ➔ 加入主畫面」全螢幕離線使用。
